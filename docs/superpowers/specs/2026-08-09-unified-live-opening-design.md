# 实时开局识别与时间线统一设计

## 目标

让单图开局确认、实时状态机和状态机视频复测共享同一套开局信号判定；新开局时只清空实时页面的内存时间线，不删除任何历史 session、录像或日志文件。

## 已确认的问题

- 加倍阶段的单图识别会把低置信度的 `first_play` 模板误匹配直接写成首出座位。
- 实时页面结束一局后保留首发下拉框和时间线部件；下一局可能把上局座位再次传入 `start_session`。
- `start_session` 将页面下拉框的值立即固化到状态机，而不是由实时开局帧确认。
- 状态机视频复测从既有 timeline 读取首出座位，因此绕过了实时开局识别。
- 当前时间线由多个不可跨条目选择的 QWidget 组成，无法通过鼠标选择并复制完整日志。

## 统一规则

### 开局信号

新增一个轻量的开局信号结果，包含：是否在超级加倍阶段、首出标志候选、计时器行动者候选、自己出牌按钮是否可见。

判定顺序：

1. 超级加倍按钮存在时，首出一定为未知；忽略所有首出/计时器候选。
2. 加倍结束后，首出标志与计时器一致时确认该座位。
3. 只有首出标志或只有计时器时，按现有连续帧稳定计数确认。
4. 两者冲突时不提交首出，继续等待下一帧。

实时页面的单图识别只填充级牌和手牌，并将首出显示为候选；开始实时对局时始终将 `lead_player=None` 交给状态机。状态机只通过上述开局信号确认首出。

### 新局页面状态

开始新 session 前，只清空页面时间线及其内存去重键；首发下拉框重置为“待自动识别”，避免复用上一局候选。历史 session 目录、录像与日志均不读取、不删除、不覆盖。

### 可复制时间线

用一个支持富文本的只读 `QTextBrowser` 取代多个不可选择的时间线卡片。普通动作按正常文字显示，DanZero 建议以青绿色富文本显示；用户可鼠标选择任意连续日志并使用 Ctrl+C 或右键复制，新增日志仍自动滚动到底部。

### 复测一致性

状态机管线复测从已知初始手牌和级牌启动，但首出传入 `None`，使视频首帧到首出阶段经过和实时完全相同的开局状态机。可信日志 DanZero 模式仍明确跳过视觉开局识别，因为它的职责是验证 reducer 与 DanZero 链路。

## 验收标准

- 新开局后界面不显示上一局时间线，但旧 session 文件仍在。
- 加倍按钮存在时，单图和实时状态机都不能提交首出。
- 单图显示的首出候选不能直接成为实时状态机初始首出。
- 首出冲突时状态机继续等待，不能提交错误座位。
- 状态机视频复测启动时首出为空，等待视频中的统一开局信号。
- 时间线可通过鼠标选择并复制，DanZero 建议保留不同颜色。
