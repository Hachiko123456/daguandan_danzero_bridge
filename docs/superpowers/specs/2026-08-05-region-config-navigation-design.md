# 区域配置与预览交互优化设计

## 目标

把区域元数据编辑从图片预览页拆出，修复选中区域和区域拖框没有视觉反馈的问题，并将图片前后切换箭头放到图片左右两侧。

## 方案

预览页继续负责截图选择、图片预览和模板裁剪。新增独立的 `RegionConfigPage` 配置窗口，负责展示和编辑“名称、角色、绝对坐标、比例坐标”，预览页只保留“查看区域配置”按钮。配置窗口与预览页通过 Qt 信号同步：选中区域时立即发送待预览区域；保存后发送更新记录，预览页重新加载区域数据。

图片区域使用横向布局：左箭头、图片画布、右箭头。图片下方保留下拉选择框，边界处按当前索引禁用对应按钮。

## 交互行为

- 配置窗口选中一行后，预览页立即用彩色矩形和中文名称显示该区域。
- “标注选中区域”按钮在配置窗口和预览页均有明确动作；没有选中区域时显示提示，有选中区域时强制刷新预览。
- 区域设置和模板裁剪共用同一个 ROI 画布。鼠标左键拖动时显示轻量级橡皮筋框，松开后保留橙色 ROI 框，并同步坐标；预览画布缩放不改变原图坐标映射。
- 区域模式下拖出的 ROI 通过配置窗口的坐标编辑器保存；模板模式下继续使用预览页的模板坐标编辑器。

## 数据与错误处理

区域名称和角色继续使用稳定的英文内部值、中文 UI 标签。保存仍由 `AnnotationService.update_region` 做坐标、重复名称和标准画面范围校验。窗口关闭、空图片、无选中行和保存失败均显示状态提示，不抛出未处理异常。

## 测试策略

- Qt 离屏测试验证配置窗口独立存在、中文列头、选中信号驱动预览、保存信号刷新数据。
- Qt 测试验证箭头位于画布左右布局、边界禁用、区域模式拖框产生可见 ROI 预览。
- 保留模板裁剪异步测试，并运行完整 pytest、compileall、Qt 栈审计和主窗口构造冒烟。
