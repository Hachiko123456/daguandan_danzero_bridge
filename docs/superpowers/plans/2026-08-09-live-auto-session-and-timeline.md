# 实时自动对局与对局动态：实施记录

## 目标与结果

已完成实时助手自动闭环及页面信息重构：点击一次“识别当前页面（持续监听）”后，控制器会等待两次相同的规范化 27 张手牌，自动创建 session；识别到继续游戏或换桌后自动封存，并恢复监听下一局。

本轮遵照用户要求：**只编写实现和单元测试，没有执行任何测试命令。**

## 实现边界

- 监听阶段只更新预览/候选，不创建 session 或录像，因此不会额外占用录像磁盘空间。
- 牌局状态的正式推进仍只由 reducer 的动作事件完成；游次和接风只作为追加时间线事件，不会改写 DanZero 输入。
- 不出仍只由 `passed.png` 模板确认，未加入“区域为空”的推断路径。
- 自动封存由控制器在主流程启动异步 `finish()`；状态机只发布结算事件，不在线程内执行录像收尾。
