1. `aedb4b` 和 `f4458c` 的“首出玩家错误”可以稳定复现为初始化基线问题：第 0 帧是开局前空画面，完整识别无法得到首出玩家。当前 UI 在没有可信首出时会从当前帧建立基线；如果基线误识别，后续状态机就会沿错误首出运行。

## 首出问题根因证据

两个问题 session 的第 0 帧完整识别结果均为：

```text
lead=None, round_level=None, hand=0
```

因此第 0 帧不能作为初始化基线。单帧按钮在后面的有效画面上识别正确，并不能证明逐帧扫描开始时使用的是同一张有效画面。没有可信日志时，首出基线必须来自有效首出画面或用户保存的初始日志，不能从空画面推断。
